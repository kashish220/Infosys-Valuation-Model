# Infosys Valuation Model

## Project Overview
This project presents a financial valuation model of Infosys Limited, developed to analyze the company's historical financial performance, forecast future performance, and estimate its intrinsic value.

## Key Analysis
- Historical Financial Statement Analysis
- Revenue and Profit Forecasting
- Ratio Analysis
- Discounted Cash Flow (DCF) Valuation
- Comparable Company Analysis
- WACC and Cost of Equity
- Terminal Value Calculation
- Sensitivity Analysis

## Tools Used
- Microsoft Excel
- Financial Modeling
- Financial Statement Analysis
- Valuation Techniques

## Company
**Infosys Limited**

**Industry:** IT Services & Consulting

## Objective
The objective of this project is to evaluate Infosys' financial performance and estimate its intrinsic value using fundamental valuation techniques.

## Disclaimer
This project is prepared for educational and analytical purposes only and should not be considered investment advice.
